자율 모의해킹 AI 에이전트

실제 해커의 사고방식을 모방하는 AI가 자율적으로 공격 경로를 탐색하고, 취약점을 발견하며, 결과를 보고서로 정리합니다.

자율 공격 루프

AI가 관찰→판단→실행→기록을 자동 반복. 사람이 일일이 지시하지 않아도 공격 경로를 스스로 탐색합니다.

ScopeGuard 범위 통제

CIDR 범위 체크, DNS 리바인딩 차단, 파괴적 명령 필터. 테스트 범위를 벗어나지 않도록 안전장치를 제공합니다.

OWASP Top 10 커버리지

XSS, SQLi, SSRF, IDOR, 파일 업로드, 인증 우회 등 OWASP Top 10 기반 웹 공격 도구 10종을 탑재합니다.

인프라 침투 도구 13종

SMB/Kerberos 열거, SSH 키 재사용, 권한 상승, 횡이동, CVE 익스플로잇(Nuclei) 등 네트워크 인프라 공격을 지원합니다.

자동 보고서 생성

발견된 취약점을 자동으로 분류·정리하여 보고서를 생성. 심각도, 재현 경로, 권장 조치를 포함합니다.

Aegis 연계

로뎀이지스(Aegis)와 연계하면 취약점 진단→모의해킹→위험평가→보고서까지 원스톱으로 수행 가능합니다.

23종 독자 공격 도구

웹 애플리케이션 10종 + 네트워크·시스템 인프라 13종. 모든 도구는 자체 개발.

웹 애플리케이션 10종

  • XSS 탐지 (Reflected/Stored/DOM)
  • SQL Injection (Union/Blind/Time-based)
  • SSRF 탐지 (클라우드 메타데이터 포함)
  • 파일 업로드 우회
  • 인증 우회 (IDOR/헤더 조작)
  • 자격증명 스프레이 (속도제한·잠금 방지)
  • 디렉토리 트래버설
  • CORS 미설정 탐지
  • 민감정보 노출 (DataMasker 적용)
  • 보안 헤더 점검

네트워크·인프라 13종

  • 포트 스캔 + 서비스 핑거프린팅
  • SMB 열거 (공유 폴더·사용자)
  • Kerberos 열거 (SPN·TGT)
  • SSH 키 재사용 횡이동
  • 패스워드 재사용 횡이동
  • SMB 횡이동 (PsExec/WMI)
  • Linux 권한 상승 (SUID/sudo)
  • CVE 익스플로잇 (Nuclei verify_only)
  • DNS 영역 전송 시도
  • SNMP 커뮤니티 스트링 탐색
  • SSL/TLS 설정 점검
  • Impacket 기반 원격 실행
  • 네트워크 취약 프로토콜 탐지
🔒 Safety

안전 메커니즘

AI 모의해킹의 핵심은 안전한 범위 통제입니다. ARES는 세 가지 안전장치로 테스트 범위를 철저히 관리합니다.

🛡

ScopeGuard

CIDR 범위 체크, target_domains 접미사 매칭으로 허가된 대상만 공격. 범위 이탈 시 즉시 차단.

🚨

KillSwitch

운영자가 언제든 즉시 중단 가능. 진행 중인 모든 공격 세션을 안전하게 종료합니다.

🚫

파괴적 명령 필터

rm -rf, DROP TABLE 등 파괴적 명령어를 사전 차단. DNS 리바인딩 공격도 방지합니다.

📊

DataMasker

발견된 민감정보(개인정보, 인증정보)를 자동 마스킹. 보고서에 원본 데이터가 노출되지 않습니다.
